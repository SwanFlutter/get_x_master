## Examples hub

`lib/main.dart` is a single page that lists every example (grouped by category,
searchable). Tap a tile to open it; use the check / cross buttons to record
whether it works. The switch in the top bar swaps the whole app between
`GetMaterialApp` and `GetCupertinoApp`, so every example can be tested under
both `material_ui` and `cupertino_ui`.

```bash
flutter run            # opens the hub
flutter run -t lib/main_classic.dart   # previous standalone demo
```

New examples are added in `lib/hub/demo_registry.dart`.
